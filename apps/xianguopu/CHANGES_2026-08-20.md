# 鲜果铺本次修改

1. 删除首页、商品详情和结算页中的三段式品质保证文案与对应占位骨架。
2. 商品卡、搜索推荐、首页时令卡、果篮、结算清单和订单详情统一使用 `¥59.9/箱` 样式，价格与单位不换行。
3. “我的”页支持微信登录；可读取微信授权资料，并支持使用微信头像选择器与昵称输入框修改资料。头像上传到服务端，名称与头像地址持久化到数据库。
4. 重新绘制首页、分类、果篮、我的 4 组底部导航图标，统一圆角、线宽和选中颜色。
5. 果篮移除免配送费进度卡及相关页面请求逻辑；结算栏固定于页面底部，按钮文案改为“结算”。
6. 时令日历按设备宽度计算水平滚动位置，选中月份始终居中显示。
7. 真机调试 API 已配置为 `10.123.92.32:8787`。
8. 首页、分类、商品详情、搜索、时令日历、产地档案、果篮、订单、结算及“我的”等所有业务图片，统一通过安全图片组件加载，不再由 WebView 直接读取局域网 HTTP 图片。
9. 图片加载器会通过 `wx.request` 获取二进制并写入小程序本地缓存；相同地址自动合并请求，全局最多并发 4 张，缓存损坏时自动清理重下，最终失败时提供点击重试。
10. 全局反查所有 WXML：除安全图片组件内部外，不再存在原生 `<image>` 直连业务地址；并修正组件包装后对首页、搜索及订单卡片尺寸造成干扰的通配选择器。

验证结果：13 个页面、36 款商品、1108 项源码断言通过；服务端 TypeScript 路由已通过 Node 语法检查。
