# 鲜果铺订单闭环与体验修复

1. 栏目眉题、导航提示、商品标签和高频辅助文字统一提高至易读字号，并加强暖白背景上的文字对比度。
2. 首页不再写死城市；服务范围和履约说明从商户设置接口读取，并可在后台“店铺设置”直接修改。
3. 商品详情新增独立的“立即购买”按钮，直接进入确认订单，不合并、不修改也不清空原购物车。
4. `Order` 新增 `isGift` 与 `deliverySlot` 字段；数据库迁移会自动整理旧订单备注中的礼赠与配送信息，保留真正的用户备注。
5. 购物车、结算页、订单接口、管理后台订单列表、订单详情和用户订单详情均已打通礼赠与配送信息。
6. 移除未被服务端验证的 `x-app-key` 和无效 `APP_KEY` 配置，保留真实有效的 Bearer Token 登录鉴权。
7. 首页商品详情分包改为仅在 Wi-Fi 下预加载；购物车订单分包继续保持进入时预加载。
8. CORS 改为可配置来源白名单，同时兼容没有 Origin 请求头的微信小程序。
9. 店铺配送设置或收货地址加载失败时，确认订单页会展示可重试错误，不会伪装成正常默认配置或空地址。
10. 全站删除旧版人物导购相关的文案和设计表述，保留中立的赏味、保存与时令信息。
11. 真机 API 与图片地址继续使用 `10.123.92.32:8787`，并完整保留全站安全图片缓存与重试方案。
12. 本版未接入真实微信支付；`PAYMENT_MODE=mock` 仍只用于本地联调。

## 升级命令

```bash
cd server
npm install
npx prisma migrate deploy
npx prisma generate
npm run dev
```

首次安装时，在执行 migration 之前先运行 `cp .env.example .env` 并启动 PostgreSQL。已有 `.env` 时不要覆盖。
