# 鲜果铺启动指南

## 最快预览

1. 在项目根目录执行 `node scripts/verify.mjs`，确认源码和 36 款商品数据完整。
2. 执行 `docker compose up -d db` 启动 PostgreSQL。
3. 新终端进入 `server/`。首次使用先执行 `cp .env.example .env`，再依次执行 `npm install`、`npx prisma migrate deploy`、`npx prisma generate`、`npm run seed`、`npm run dev`。
4. 微信开发者工具直接导入本项目根目录；`project.config.json` 已指向 `miniprogram/`。
5. 开发者工具中打开“详情 → 本地设置”，本地联调时关闭合法域名校验。

## 当前真机调试地址

项目已按本机局域网 IP `10.123.92.32` 配置：

```text
API:    http://10.123.92.32:8787/api
静态资源: http://10.123.92.32:8787
健康检查: http://10.123.92.32:8787/health
```

手机和电脑需连接同一 Wi-Fi。先在手机 Safari 打开健康检查地址，能看到 `ok: true` 后再启动真机调试。如果电脑网络变化导致 IP 改变，只需更新 `miniprogram/config/env.js`。

## 微信登录与资料

- “我的”页点击会员卡即可调用微信登录。
- 微信允许返回头像和昵称时会自动保存。
- 用户也可点击“编辑资料”，通过微信头像选择器和昵称输入框修改资料。
- 头像会上传到 `server/public/uploads/avatars/`，昵称与头像地址保存到用户表。

修改了服务端路由后需要重新启动 `server`。本地未配置微信 AppID/AppSecret 时使用联调账号；生产环境必须配置真实微信参数。

## 管理后台

新终端进入 `admin/`，执行：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。

- “店铺设置”可以编辑首页显示的服务范围与履约说明，例如“天津 · 今日鲜达”或“全国 · 应季鲜达”。
- “订单管理”会标记礼赠订单，并展示期望配送时段、客户原始备注和完整收货地址。
- 如后台使用其他域名，在 `server/.env` 的 `CORS_ALLOWED_ORIGINS` 中追加其完整来源。

## 页面与加载状态

- 首次进入：首页、分类、商品详情、订单和地址页使用骨架屏。
- 刷新数据：保留当前内容，只显示轻量同步提示。
- 图片加载：全站业务图片统一由安全图片组件加载。局域网 HTTP 图片会先通过 `wx.request` 下载到小程序本地缓存，再交给页面显示；相同图片会合并请求，最多同时下载 4 张，失败后可原地重试。
- 关键提交：加购、登录、保存资料、保存地址和提交订单均有防重复状态。
- 请求失败：页面内显示失败原因，可原地重试，不会留下空白页。

## 从旧版本更新后

1. 关闭旧项目，解压并重新导入本完整工程，不要把新文件零散覆盖到旧目录。
2. 在微信开发者工具中选择“清缓存 → 全部清除”。
3. 重新编译，退出旧的真机调试连接，再重新进入真机调试。
4. 这次新增了订单礼赠与配送字段。进入 `server/` 执行 `npx prisma migrate deploy`、`npx prisma generate`，然后重启 `npm run dev`；不需要删除数据库或重新导入现有订单。

## 下单方式

- “加入果篮”只修改当前购物车，适合继续挑选。
- “立即购买”直接进入确认订单，不合并购物车，也不会清空原有购物车商品。
- 礼赠包装、配送时段和用户备注分别保存，后台客服可以直接识别并处理。
- `PAYMENT_MODE=mock` 仍仅用于联调；正式收款需要另外接入微信支付 JSAPI。
