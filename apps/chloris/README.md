# Chloris（克罗丽丝）V6.19 优惠券与物流运营版

Chloris 是一套自营鲜花零售项目，包含微信小程序、CloudBase 云函数和 Vue 3 商户管理后台。本版新增完整优惠券闭环、独立物流信息页，并从日历中移除商家活动内容。

## 本版重点

### 优惠券

- 顾客端：我的优惠券、可用/已使用/已过期分类、订单结算自动推荐最佳优惠券、手动切换或不使用优惠券。
- 订单规则：一单一券、优惠只抵商品金额、不抵配送费、提交订单后锁券 15 分钟、未付款取消后自动返还。
- 运营规则：新客券、日常满减券、复购券、售后补偿券、不定期惊喜券。
- 惊喜券控制：同一顾客 30 天最多 1 张、滚动 90 天最多 3 张；已有同等或更高优惠的有效券时不重复发放。
- 后台：优惠券模板 CRUD、指定用户/全部用户/沉睡用户发放、总量与预算控制、固定或相对有效期、指定品类和活动排除。
- 后台提供“一键初始化推荐券”，自动创建此前确认的推荐规则模板。

### 物流

- 订单详情新增“查看物流”，进入独立物流信息页。
- 展示承运公司、运单号、物流状态、轨迹时间线和收货信息。
- 后台订单页可录入或更新快递公司及运单号。
- 可选接入快递100实时查询；未配置接口时仍可展示承运公司和运单号。
- 物流查询结果缓存 30 分钟，减少重复请求。

### 日历

- 顾客端只保留国内节日、国际节日和 BIG DAY。
- Web 后台节日管理不再提供商家活动类型。
- 云端会忽略历史 `region = merchant` 的商家活动记录。

## 清理内容

本版已删除未注册且不再使用的旧图鉴页面、图鉴本地收藏/购买服务以及系统生成的 `.DS_Store` 等无用文件。

## 说明

项目当前仍未接入真实微信支付与自动退款。优惠券已完成结算、锁定、订单占用和取消返还逻辑；接入真实支付时，应在支付成功回调中将券标记为已使用，并在退款流程中执行对应返券规则。
