# Chloris V6.11.1 性能与完整性整理

本版本不调整现有业务功能和页面排版，仅进行性能、构建与项目完整性整理。

## 已处理

- Web 后台改为按需加载 Element Plus 组件与样式，减少首屏资源体积。
- Web `dist` 全量重新构建，清除历史构建残留文件。
- 修复数据导入模板的乱码文件名，并删除重复模板。
- 压缩小程序启动 Logo 与顶部 Logo，保持原尺寸和透明背景。
- 为订单、报价、包装与节日推荐等列表图片补充延迟加载。
- 删除未被任何页面或代码引用的组件、图片和重复配置文件。
- 删除机器本地专用的 `project.private.config.json`。
- 明确设置 Vite `emptyOutDir: true`，后续构建自动清理旧资源。

## 检查结果

- Web 生产构建通过。
- Web 本地预览及静态资源访问通过。
- 小程序、云函数和 Web JavaScript 语法检查通过。
- 小程序页面、组件、事件处理函数与静态资源引用检查通过。
- 所有 JSON 配置文件可正常解析。
- 五个 Excel 导入模板结构和压缩包校验通过。
- Web 与云函数 `package.json` / `package-lock.json` 依赖一致。
