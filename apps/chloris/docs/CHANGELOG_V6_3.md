# Chloris V6.3 变更记录

## 小程序

- 更新顶部品牌 Logo；
- 首页“开始选择”去除箭头，并同步三步筛选文案；
- 新增通用 `price-range` 价格范围组件；
- 帮我选花取消作品类型，改为对象、颜色、最低预算和最高预算；
- 分类页改为拖动价格范围；
- 定制报价联系人和手机号改为必填，并加入微信客服入口；
- 日历标题改为“日历”，BIG DAY 取消偏好分类；
- 我的页面取消会员标识，客服改为原生客服按钮；
- 统一调整右箭头与文字的垂直对齐；
- 下拉刷新阈值提高到 120，系统级容易误触的下拉刷新关闭；
- 首页数据请求增加并发合并与缓存，分类搜索增加防抖，报价图片改为并行上传。

## 云函数

- `userApi` 校验并保存定制报价联系人与手机号；
- 联系信息同步写入用户记录，后续报价自动预填；
- 定制需求继续绑定用户 ID、昵称和图片。

## Web 管理中心

- 图片定制报价列表突出联系人、手机号和用户 ID；
- 增加复制手机号操作；
- 已重新执行生产构建。
