# Chloris V6.13 商业运营版

## 已完成

- 情人节预定与节日预售完整后台：开放时间、预约截止、配送日期、订单上限、产能上限、关联商品与实时预售进度。
- 限时推出后台化：支持活动级和商品级开始/结束时间，顾客端按时间自动展示、自动下架。
- 节日活动商品管理：活动保存后自动同步关联商品的销售模式、预售窗口和配送区间。
- 商品新增“现货销售 / 预约销售”两种模式，并支持单品预约限量、单件产能单位和指定履约工作室。
- 工作室合作后台：工作室资料、每日订单上限、每日产能单位、特殊日期调整/停接、订单接单、确认制作。
- 接单时校验工作室指定日期的订单数和产能，不允许超限接单。
- 节日活动和预约商品在下单时校验活动是否开放、单品名额、活动订单上限与活动产能上限。
- 现货配送最早为下单后两小时；预约商品必须在活动配送区间内选择。
- 删除顾客端、云函数和商户后台中的图鉴与积分功能；优惠券保留。
