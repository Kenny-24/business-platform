# 花予 V4.0 · 用户、地址与订单闭环

本版本在现有首页、分类、日历、购物车、我的、图鉴与后台基础上，新增真实顾客身份、收货地址、订单确认、顾客订单、后台订单管理和顾客管理。

## 已完成

- 云函数根据微信 OPENID 自动建立顾客记录；
- 顾客资料、头像和地址管理；
- 购物车进入订单确认页；
- 云函数重新校验商品价格、库存和上下架状态；
- 提交后进入待确认订单；
- 后台确认配送费用、拒单、确认线下收款、开始配送、完成或取消订单；
- “我的”页面同步真实订单和地址数量；
- 有效订单自动收录对应花材图鉴。

## 本版本暂不包含

- 微信支付；
- 库存锁定与扣减；
- 退款；
- 复杂积分、优惠券和会员营销。

部署步骤见：`docs/07_V4.0_部署指南.md`。
