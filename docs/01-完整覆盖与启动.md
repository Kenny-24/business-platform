# 1. 完整覆盖与启动

## 覆盖目录

当前项目路径：

```text
/Users/macz/WeChatProjects/huayu-miniapp
```

先备份，然后用本包覆盖下面三个目录：

```text
miniprogram/
cloudfunctions/
huayu-admin-web/
```

保留你原来的：

```text
project.config.json
project.private.config.json
```

## 部署两个云函数

在微信开发者工具中分别右键：

```text
cloudfunctions/getHomeData
cloudfunctions/adminApi
```

选择：

```text
上传并部署：云端安装依赖
```

## 编译小程序

```text
工具 → 清除缓存 → 全部清除 → 重新编译
```

首页与分类页会通过 `getHomeData` 读取真实商品。数据库永久保存 `cloud://` File ID，云函数负责生成临时 HTTPS 地址。

## 启动管理后台

先在 CloudBase 控制台创建 Publishable Key，然后填入：

```text
huayu-admin-web/public/huayu-config.js
```

再执行：

```bash
cd /Users/macz/WeChatProjects/huayu-miniapp/huayu-admin-web
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:5173
```
