# 3. 主要数据字段

## products

```json
{
  "type": "flower",
  "name": "香槟玫瑰",
  "subtitle": "温柔优雅",
  "priceFen": 1200,
  "unit": "枝",
  "stock": 36,
  "onSale": true,
  "featured": true,
  "sceneTags": ["自我取悦", "节日送礼"],
  "colorTags": ["香槟色", "奶油色"],
  "coverFileId": "cloud://...",
  "sort": 100
}
```

商品类型：

```text
flower       鲜切花材
bouquet      成品花束
succulent    多肉植物
greenPlant   绿植
vase         花器
gift         礼品
```

价格统一以“分”为单位保存。
