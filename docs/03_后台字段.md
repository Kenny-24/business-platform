# 后台字段

## 商品 products

核心字段：`type`、`name`、`priceFen`、`unit`、`stock`、`onSale`、`featured`、`sceneTags`、`colorTags`、`searchKeywords`、`coverFileId`、`sort`。

## 横幅 banners

`placement=home` 用于首页；`placement=categoryHero` 用于分类页。

## 图鉴 atlas

```json
{
  "name": "玫瑰",
  "latinName": "Rosa",
  "meaning": "温柔与偏爱",
  "description": "花材介绍",
  "careGuide": "养护说明",
  "category": "鲜切花",
  "sceneTags": ["节日送礼"],
  "colorTags": ["粉色"],
  "seasonTags": ["全年"],
  "imageFileId": "cloud://...",
  "homeFeatured": true,
  "published": true,
  "sort": 100
}
```

- `published=true`：进入完整图鉴“全部”；
- `homeFeatured=true`：优先显示在首页；
- 首页按“首页精选、排序值”取前 3 条。
