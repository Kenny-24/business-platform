# 覆盖与启动

## 覆盖前备份

先保存旧项目中的：

- `project.config.json` 真实 AppID；
- `huayu-admin-web/public/huayu-config.js` Publishable Key；
- 云函数 `adminApi` 的 `HUAYU_BOOTSTRAP_CODE` 环境变量。

## 覆盖

将完整 `huayu-miniapp` 文件夹放到你的微信项目目录。交付包未包含 `.DS_Store`，无需恢复。

## 小程序

微信开发者工具依次执行：

```text
工具 → 清除缓存 → 全部清除 → 重新编译
```

## Web 后台

```bash
cd huayu-admin-web
npm ci --no-audit --no-fund --progress=false
npm run dev
```

## 云函数

分别右键：

```text
cloudfunctions/getHomeData
cloudfunctions/adminApi
```

选择“上传并部署：云端安装依赖”。
