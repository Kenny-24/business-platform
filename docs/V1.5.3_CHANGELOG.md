# 花予 V1.5.3 顶部导航优化

## 修改内容

1. “花予”不再使用系统实时字体渲染，改用透明品牌图片：
   - iOS 与安卓显示完全一致；
   - 更接近 POPPY 的粗体、简约、几何感；
   - 字号缩小；
   - 向上微调，改善视觉垂直居中。

2. 定位图标替换为新的轻量线性图标：
   - 图标宽高统一；
   - 与文字比例更协调；
   - 提供绿色和白色两套资源；
   - 滚动前后自动切换。

## 推荐替换方式

1. 备份现有 `miniprogram`；
2. 删除现有整个 `miniprogram` 文件夹；
3. 将本包中的完整 `miniprogram` 放回项目根目录；
4. 保留：
   - `cloudfunctions/`
   - `project.config.json`
   - `project.private.config.json`
5. 清除全部缓存后重新编译。

无需安装依赖，也无需构建 npm。
