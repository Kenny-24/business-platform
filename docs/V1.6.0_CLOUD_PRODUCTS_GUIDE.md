## 替换方式

1. 备份并删除当前项目中的整个 `miniprogram` 文件夹；
2. 将本包中的完整 `miniprogram` 放入项目根目录；
3. 保留原项目中的：
   - `cloudfunctions/`
   - `project.config.json`
   - `project.private.config.json`
4. 微信开发者工具执行：
   - 工具；
   - 清除缓存；
   - 全部清除；
   - 重新编译。

不需要 `npm install`，也不需要构建 npm。
