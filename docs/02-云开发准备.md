# 2. 云开发准备

环境 ID：

```text
cloudbase-d6gspds9z5e38b6f0
```

## 数据集合

至少需要：

```text
products
admins
banners
atlas
```

请在云开发控制台一次性创建这四个空集合。之后所有记录都通过 Web 后台维护，不需要再手工填写 JSON。

## Web 登录

CloudBase 控制台：

```text
身份认证 → 常规登录 → 开启用户名密码登录
```

首次初始化管理员期间允许注册；管理员创建完成后可关闭普通用户自行注册。

## Publishable Key

CloudBase 控制台：

```text
设置 / API Key 配置 → 新建 Publishable Key
```

填入：

```text
huayu-admin-web/public/huayu-config.js
```

Publishable Key 可用于浏览器前端。不要把 SecretId 或 SecretKey 放入网页。

## 初始化管理员

开发阶段默认初始化码：

```text
HUAYU-INIT-2026
```

正式使用前，在 `adminApi` 云函数环境变量中添加：

```text
HUAYU_BOOTSTRAP_CODE=你自己的复杂初始化码
```
