# 功能说明

## 经营概览

- 全部商品数；
- 正在销售商品数；
- 库存紧张与售罄提醒；
- 首页推荐、轮播与图鉴内容数量。

## 商品管理

- 新增、编辑、删除商品；
- 鲜切花材、成品花束、多肉、绿植、花器、礼品分类；
- 商品图片上传；
- 价格、单位、库存、场景标签、颜色标签；
- 上下架、首页推荐、排序；
- 搜索与筛选。

## 库存管理

- `-10 / -1 / +1 / +10` 快速调整；
- 直接输入库存；
- 450ms 防抖自动保存；
- 低库存和售罄颜色提示。

## 首页轮播

- 图片、场景、标题、副标题、按钮文案；
- 跳转类型、跳转值；
- 启用状态与排序。

数据写入 `banners` 集合。

## 花予图鉴

- 中文名称、拉丁名；
- 花语、介绍、养护说明；
- 适用场景、图片；
- 发布状态与排序。

数据写入 `atlas` 集合。

## 数据安全

浏览器不直接修改数据库。所有新增、修改、删除操作统一调用 `adminApi`，云函数每次都会检查当前登录用户是否属于 `admins` 集合。
