# 部署到 CloudBase 静态网站托管

## 1. 构建

```bash
cd huayu-admin-web
npm install
npm run build
```

生成：

```text
dist/
```

## 2. 安装 CloudBase CLI

```bash
npm i -g @cloudbase/cli
tcb login
```

## 3. 部署

```bash
tcb hosting deploy dist -e cloudbase-d6gspds9z5e38b6f0
```

本项目使用 Hash 路由，刷新子页面不会产生 SPA 404。

## 4. 更新后台

以后修改代码后重新执行：

```bash
npm run build
tcb hosting deploy dist -e cloudbase-d6gspds9z5e38b6f0
```
