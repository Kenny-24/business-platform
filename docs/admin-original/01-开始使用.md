# 花予商户后台：开始使用

## 1. 把文件放到现有项目

解压后，将下面两个文件夹复制到当前小程序项目根目录：

```text
huayu-miniapp/
├── cloudfunctions/
│   ├── getHomeData/
│   ├── quickstartFunctions/
│   └── adminApi/             ← 新增
├── miniprogram/
├── huayu-admin-web/          ← 新增
├── project.config.json
└── project.private.config.json
```

`cloudfunctions` 选择合并，不要删除原来的 `getHomeData`。

## 2. 部署 adminApi 云函数

在微信开发者工具左侧找到：

```text
cloudfunctions/adminApi
```

右键选择：

```text
上传并部署：云端安装依赖
```

部署完成后，云开发控制台的云函数列表里应出现 `adminApi`。

## 3. 创建 Web Publishable Key

CloudBase Web SDK 需要 Publishable Key。进入 CloudBase 控制台：

```text
设置 / API Key 配置
→ 新建 Publishable Key（可发布密钥）
```

复制后打开：

```text
huayu-admin-web/public/huayu-config.js
```

把：

```javascript
accessKey: '请替换为CloudBase-Publishable-Key'
```

替换为实际 Publishable Key。

注意：这里只能填写 Publishable Key，绝对不要填写 SecretId、SecretKey。

## 4. 开启用户名密码登录

进入 CloudBase 控制台：

```text
身份认证
→ 登录方式
→ 开启“用户名密码登录”
```

第一次创建管理员时，还需要允许 Web 用户注册。首位管理员创建成功后，可以关闭普通用户自行注册。

## 5. 启动后台

### 方法一：双击启动

在 Finder 中进入：

```text
huayu-admin-web/
```

双击：

```text
启动后台.command
```

macOS 第一次拦截时，右键该文件选择“打开”。

### 方法二：终端启动

```bash
cd /Users/macz/WeChatProjects/huayu-miniapp/huayu-admin-web
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:5173
```

## 6. 创建首位管理员

登录页切换到“首次初始化”，填写：

```text
显示名称：花予店主
用户名：例如 huayu_owner
密码：至少 8 位
初始化码：HUAYU-INIT-2026
```

创建成功后，系统会自动建立 `admins` 集合并写入首位店主。以后使用“管理员登录”。

## 7. 安全建议

正式使用前，在 CloudBase 控制台给 `adminApi` 添加环境变量：

```text
HUAYU_BOOTSTRAP_CODE=你自己设置的一串复杂字符
```

修改后重新部署 `adminApi`。首次管理员已创建后，初始化接口也会自动锁定。
