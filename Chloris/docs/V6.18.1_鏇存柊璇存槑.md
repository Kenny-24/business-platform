# Chloris V6.18.1 更新说明

## 购物车输入区

- 贺卡内容与买家留言改为清晰的独立输入区域。
- 增加用途说明、选填标识、输入背景、描边和字数提示。
- 贺卡内容会随花束展示给收花人；买家留言仅供商家制作与配送参考。
- 输入内容继续自动保存，进入订单时随订单提交。

## 购物车性能

- 首屏优先读取本地购物车与缓存地址，先完成页面渲染。
- 云端库存、价格、结算配置改为首屏之后延迟同步。
- 避免页面首次进入时重复读取购物车、重复请求结算配置和重复预览金额。
- 云端商品同步增加间隔控制，短时间反复进入购物车不重复请求。
- 结算上下文增加短时复用，减少返回页面后的重复加载。
- 贺卡与留言的本地保存改为防抖写入，避免每输入一个字都同步写缓存。
- 页面离开时会清理计时器并立即保存尚未落盘的留言内容。

## 部署

本版本只修改小程序端购物车页面，不需要重新部署云函数，也不需要重新构建 Web 后台。
