# Chloris V6.16 LV 视觉与到店取货完整优化

## 顾客端

- 全局字体层级按高端零售页面重新校准：正文、标签、价格和操作按钮整体提高可读性。
- 输入框和主要信息统一左对齐，重要信息不再使用极小字号。
- 购物车新增“配送到家 / 到店取货”双选模式。
- 订单结算新增自提门店选择、门店地址、电话、营业时间和到店提示。
- 配送与自提均支持双列联动日期、时段选择。
- 到店取货订单无需填写收货地址，配送费用为 0。
- 订单列表与订单详情可区分“备货中 / 待取货”等状态。
- 图片定制报价生成订单时同样支持配送到家或到店取货。

## 云函数

- `orderApi`：新增自提门店读取、校验、订单快照和自提状态展示。
- `userApi`：图片定制报价订单支持到店取货。
- `adminApi`：工作室新增自提配置，并优化自提订单的工作室路由。

## Web 后台

工作室合作后台新增：

- 是否开放到店取货
- 顾客端门店名称
- 自提地址
- 自提电话
- 自提营业时间
- 到店提示

订单管理与详情页可显示自提门店和预约自提时间。
