# Chloris V6.14 全局视觉统一版

本版本仅调整小程序视觉样式，不修改页面功能、业务状态、数据库结构、云函数接口或 Web 后台逻辑。

## 统一视觉规范
- 以已确认的商品详情页为基准：黑、白、中性灰。
- 普通内容卡片改为直角细边框，无阴影。
- 主按钮统一黑底白字圆角胶囊；次按钮统一白底黑边。
- 输入框、说明块统一浅灰背景与细分隔线。
- 商品图片区域统一浅灰展示背景。
- 导航栏、底部栏和弹窗统一中性黑白样式。
- TabBar 选中图标改为黑色，未选中改为中性灰。

## 保持不变
- 页面结构与跳转
- 订单、报价、配送、优惠券、购物车等功能
- 云函数与数据库
- Web 管理后台功能与样式
